# C-_-language

A small collection of beginner-level C++ programs for learning basic syntax, input/output, arithmetic, conditionals, and function usage.

## Programs included

- `1st.cpp` – Simple program that stores and prints the sum of 5 and 6.
- `add_two_number.cpp` – Reads two numbers from the user and prints their sum.
- `even_or_odd_number.cpp` – Checks whether a number is even or odd.
- `self_answer.cpp` – Demonstrates a function-based addition example using user input.

## How to compile and run

Use `g++` from the terminal in this project folder:

```bash
g++ 1st.cpp -o 1st
./1st
```

For the other examples:

```bash
g++ add_two_number.cpp -o add_two_number
./add_two_number
```

```bash
g++ even_or_odd_number.cpp -o even_or_odd_number
./even_or_odd_number
```

```bash
g++ self_answer.cpp -o self_answer
./self_answer
```

## Learning focus

This repo is intended for students who are practicing:

- variable declaration and assignment
- standard input/output with `cin` and `cout`
- arithmetic operations
- `if`/`else` logic
- functions and return values

These programs are intentionally simple and easy to read for beginners.
